How to install

Scripts are served as standard userscripts compatible with Tampermonkey, Violentmonkey, and Greasemonkey.

  1. Install a userscript manager extension for your browser.
  2. Click the Install button next to any script below.
  3. Your userscript manager will show the installation dialog — confirm to proceed.
  4. Future updates are delivered automatically via the @updateURL embedded in each script.

Available endpoints

Method Path Description
GET /{repo_uuid}/{script_uuid}/{slug}.user.js Full userscript with rewritten metadata
GET /{repo_uuid}/{script_uuid}/{slug}.meta.js Metadata block only — used for lightweight update checks
GET /api/scripts JSON list of all available scripts
GET /health Health check for reverse-proxy / uptime monitors
